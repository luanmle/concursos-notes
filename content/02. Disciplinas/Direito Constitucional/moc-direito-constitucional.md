## 🗂️ Ementa (tópicos e subtópicos)

| Tópicos e Subtópicos de Direito Constitucional |
| :--- |
| **1. Teoria da Constituição** |
| ↳ Classificação das Constituições |
| ↳ Poder Constituinte Originário e Derivado |
| ↳ Aplicabilidade e Interpretação das Normas Constitucionais |
| **2. Direitos e Garantias Fundamentais** |
| ↳ Direitos e Deveres Individuais e Coletivos |
| ↳ Remédios Constitucionais (HC, HD, MS, MI, AP) |
| ↳ Direitos Sociais |
| ↳ Nacionalidade |
| ↳ Direitos Políticos e Partidos Políticos |
| **3. Organização do Estado** |
| ↳ Estrutura Federativa (União, Estados, DF, Municípios) |
| ↳ Repartição de Competências |
| ↳ Intervenção Federal e Estadual |
| **4. Administração Pública** |
| ↳ Disposições Gerais (Art. 37 e 38) |
| ↳ Servidores Públicos (Art. 39 a 41) |
| **5. Organização dos Poderes** |
| ↳ Poder Legislativo |
| ↳ Processo Legislativo |
| ↳ Poder Executivo |
| ↳ Poder Judiciário |
| **6. Funções Essenciais à Justiça** |
| ↳ Ministério Público |
| ↳ Advocacia Pública, Advocacia e Defensoria Pública |
| **7. Controle de Constitucionalidade** |
| ↳ Sistemas e Vias de Controle (Difuso e Concentrado) |
| ↳ Ações Constitucionais (ADI, ADC, ADO, ADPF) |
| **8. Sistema Tributário Nacional** |
| ↳ Princípios Gerais |
| ↳ Limitações ao Poder de Tributar |
| ↳ Impostos da União, Estados e Municípios |
| ↳ Repartição das Receitas Tributárias |
| **9. Finanças Públicas** |
| ↳ Normas Gerais |
| ↳ Orçamentos (PPA, LDO, LOA) |
| **10. Ordem Econômica e Social** |
| ↳ Princípios Gerais da Atividade Econômica |
| ↳ Seguridade Social |
| ↳ Educação, Cultura e Desporto |
| ↳ Meio Ambiente |
